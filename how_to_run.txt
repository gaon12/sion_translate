sion_translate.zip을 GPU 서버에서 실행하는 방법

전제
----

- ZIP에는 프로젝트와 data/*.jsonl, data/evaluation_only가 함께 들어 있습니다.
- data/excluded, 과거 artifacts/runs/checkpoint는 의도적으로 들어 있지 않습니다.
- Python 3.11 또는 3.12, NVIDIA 드라이버와 CUDA 지원 PyTorch 2.8 이상을
  권장합니다.


1. ZIP 검증과 압축 해제
-----------------------

배포자가 전달한 SHA-256과 첫 명령의 출력이 같은지 확인하세요.

sha256sum sion_translate.zip
python3 -m zipfile -t sion_translate.zip
unzip sion_translate.zip
cd sion_translate
python3 scripts/package_gpu_bundle.py verify-tree .

검증이 실패하면 파일이 빠졌거나 전송 중 손상된 것이므로 진행하지 마세요.


2. 패키지 설치와 CUDA 확인
--------------------------

nvidia-smi
python3 -m pip install --upgrade pip
python3 -m pip install -e ".[dev,export,hangul]"

python3 - <<'PY'
from importlib.metadata import version
import torch
parsed = tuple(map(int, version("torch").split("+")[0].split(".")[:2]))
assert parsed >= (2, 8), torch.__version__
assert torch.cuda.is_available(), "CUDA 지원 PyTorch가 아닙니다"
print("PyTorch:", torch.__version__, "CUDA:", torch.version.cuda)
print("GPU:", [torch.cuda.get_device_name(i) for i in range(torch.cuda.device_count())])
print("NCCL:", torch.distributed.is_nccl_available())
PY

PyTorch가 없다면 https://pytorch.org/get-started/locally/ 의 공식 선택기에서
Linux/Pip/서버에 맞는 CUDA 빌드를 먼저 설치하세요. nvidia-smi에 보이는 숫자만
보고 임의의 wheel URL을 선택하지 마세요.


3. 실행
-------

python3 easy_run.py

설치 뒤 학습 명령은 위 한 줄뿐입니다. 이 명령은 CUDA/NCCL 확인, shard 구조
검사, 선택적 RAM 디스크 복사, tokenizer와 dataset 생성, byte-fallback 및
MorphoScript sidecar 검증, 모든 GPU를 사용한 SFT 사전학습, MRT 사후학습을
순서대로 수행합니다.

대화형 셸이고 tmux가 이미 있으면 체크아웃마다 고유한 세션에서 재실행합니다.
tmux가 없으면 설치를 강제하지 않고 현재 프로세스에서 계속합니다. Slurm/nohup/
컨테이너에서는 자동으로 foreground 경로를 사용합니다.

tmux를 명시적으로 끄기:

SION_NO_TMUX=1 python3 easy_run.py


4. 자동 GPU 정책
----------------

- A100/H100을 포함해 보이는 CUDA GPU를 모두 사용합니다.
- 모든 rank가 native BF16이면 BF16, 하나라도 아니면 자동 설정은 FP16입니다.
- 가장 작은 GPU VRAM을 기준으로 batch와 activation checkpointing을 정합니다.
- 여러 GPU인데 NCCL이 없으면 긴 전처리 전에 중단합니다.
- 사후학습의 후보 생성은 micro-batch 1로 시작합니다.
- torch.compile은 사용자가 설정에서 명시하지 않는 한 자동으로 켜지 않습니다.

configs/sion_1_3b.yaml, sion_8b.yaml, sion_32b.yaml은 파일 주석에 적힌 80GB급
GPU 수를 전제로 한 수동 용량 기준입니다. easy_run.py는 이 파일을 자동으로
선택하지 않고 sion_translate.yaml의 보수적인 자동 경로를 사용합니다.


5. 상태, 결과와 재개
--------------------

GPU 상태:

watch -n 2 nvidia-smi

주요 결과:

- SFT best: runs/auto/pretrain/exports/best
- 최종 MRT best: runs/auto/posttrain/exports/best
- 재개 checkpoint: 각 단계의 checkpoints/latest
- tokenizer/sidecar: artifacts/tokenizer
- indexed dataset: artifacts/dataset

중단되면 같은 `python3 easy_run.py`를 다시 실행하세요. 단계별 latest에서
자동으로 재개합니다. 인스턴스를 종료하기 전에는 runs/와
artifacts/tokenizer/를 반드시 내려받으세요. 메타데이터·SHA-256·언어 태그·
숫자 분리 정책이 현재 설정과 다르면 기존 산출물은 자동 재사용되지 않습니다.


6. 선택 검증
------------

ruff format --check .
ruff check .
python3 -m pytest -p no:cacheprovider

실제 GPU 오류를 보고할 때는 전체 traceback과 함께 다음을 보존하세요.

nvidia-smi
python3 -m torch.utils.collect_env
